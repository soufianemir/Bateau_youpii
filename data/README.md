# Generated maritime snapshots

This directory contains small browser-ready snapshots produced from official/open sources by GitHub Actions.

- `shom-achare.geojson`: SHOM anchorage areas
- `shom-resare.geojson`: SHOM restriction areas
- `shom-fairwy.geojson`: SHOM fairways
- `shom-seabed.geojson`: SHOM seabed nature layer
- `cacem-cannes.geojson`: CACEM regulations clipped around Cannes
- `avurnav.json`: active Mediterranean AVURNAV filtered around Cannes
- `sentinel-latest.json`: latest Copernicus STAC metadata for Sentinel observations
- `source-status.json`: provider freshness/health

Generated files are cacheable application data, not a replacement for the authoritative legal texts or navigation-grade charts.
